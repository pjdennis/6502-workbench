DESCRIPTION: Error inside a parameterised macro names the macro itself in the traceback (not the first parameter's name). Regression test for a TOKEN-clobbering bug in expand_macro that has been latent since asm15 -- TOKEN held the macro name on entry, but the param-copy loop overwrote it before push_memory_source captured the frame name; pushing the memory frame earlier (right after push_label_scope) is the fix.

 4:   .endmacro

  expanded from {{MAIN_FILE}}:5

NAME: macro_error_traceback_with_identifier_arg
DESCRIPTION: When a parameterised macro is invoked with a label (identifier) argument, parse_expression's read_token clobbers TOKEN with the label's name. The traceback for an error in the macro body must still name the macro itself, not the label. This pins down the second TOKEN-clobbering path: the original Phase-4-era regression test used a hex literal arg (read_hex doesn't touch TOKEN), so it didn't catch the identifier-arg case. Fixed by pushing the memory frame BEFORE arg parsing -- the push captures TOKEN's macro-name value into the frame's name region, after which TOKEN is free to be clobbered by anything.
INPUT:
 1: somelabel = $42
 2: * = $0200
 3:   .macro mymac param
 4:   LDA undefined
 5:   .endmacro
 6:   mymac somelabel
EXPECT_STDERR:
Error 1 in macro mymac at line 1: Label not found
  expanded from {{MAIN_FILE}}:6

NAME: macro_outer_param_resolves_after_inner_pops
DESCRIPTION: Outer macro references its own parameter AFTER an inner macro has been invoked and popped. The post-inner reference must resolve through outer's scope -- which means the cached pointer triple (MACRO_LOOKUP_FRAME16 / _SLOTS16 / _PARAMS16) was correctly restored from outer's scope_block on inner's pop. If any of the three pointers stayed at inner's value, the post-inner lookup would resolve to inner's slot or fail. Pins the lockstep restore invariant.
INPUT:
 1: * = $0200
 2:   .macro inner y
 3:   LDA #y
 4:   .endmacro
 5:   .macro outer x
 6:   inner $99
 7:   LDA #x
 8:   .endmacro
 9:   outer $42
EXPECT_HEX: a9 99 a9 42
