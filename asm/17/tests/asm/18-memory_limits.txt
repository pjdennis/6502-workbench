NAME: macro_nesting_overflow
DESCRIPTION: Macro nesting itself triggers source-stack OOM under small_heap. The chain is paramless and contains no .include, so during the cascade the only thing growing is the source stack -- macro definitions are all set up before invocation (heap stable thereafter), no parameters means no per-invocation hash_add (heap doesn't grow during cascade), no .include means no extra file frames. With small_heap shrinking the heap-vs-source-stack buffer to 384 bytes the cascade exhausts the buffer mid-expansion. The traceback (EXPECT_STDERR) confirms the OOM site is a macro push during a chain of expansions. The exact depth at which the limit hits depends on the input filename's length (it counts toward the input file frame's size) and on the macro frame's payload size. Both runners (Python harness and self-hosted) now feed the assembler the same TR_INPUT_FILE basename, so the cascade reaches a deterministic depth across machines and runners; with the current 11-byte scope_block the limit hits during the push of C inside macro D (E -> D -> push-C fails).
ARGS: debug small_heap
INPUT:
 1: * = $0200
 2:   .macro A
 3:   NOP
 4:   .endmacro
 5:   .macro B
 6:   A
 7:   .endmacro
 8:   .macro C
 9:   B
10:   .endmacro
11:   .macro D
12:   C
13:   .endmacro
14:   .macro E
15:   D
16:   .endmacro
17:   E
EXPECT_STDERR:
Error 35 in macro D at line 1: Out of memory
  expanded from macro E:1
  expanded from {{MAIN_FILE}}:17

NAME: macro_max_name_args_fit_frame
DESCRIPTION: 127-character macro name (the TOKEN buffer cap) with 8 parameters fits in the 1-byte frame_size at offset 0. Worst-case frame here = 1 (frame_size) + 1 (curr_type) + 1 (prev_type) + 2 (line) + 2 (prev_data) + 127 (name) + 1 (null) + 31 (8 slots + 7-byte scope tail) = 166 bytes. With MACRO_MAX_ARGS now capped at 32, the worst-case frame across ALL legal macros is 15 + 127 + 96 = 238 bytes -- comfortably under 256 -- so the max-args ceiling is independent of name length.
INPUT:
 1: * = $0200
 2:   .macro AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA a0, a1, a2, a3, a4, a5, a6, a7
 3:   LDA #a0
 4:   .endmacro
 5:   AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA $42, $00, $00, $00, $00, $00, $00, $00
EXPECT_HEX: a9 42
