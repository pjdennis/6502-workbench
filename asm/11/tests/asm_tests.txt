# Test suite for asm11 assembler
# Features: standard 6502 syntax, .include, .zeropage/.code sections,
#   DATA (not .data), character literals, <> byte selectors, local labels,
#   forward ref tracking
# Does NOT have: expressions, .data/.byte/.word, .ifdef, macros

# ============================================================================
# POSITIVE TESTS - Valid assembly
# ============================================================================

---
NAME: implied_mode
INPUT:
1: * = $0200
2:   NOP
3:   RTS
