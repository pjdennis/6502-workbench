# Format:
#   --- separates test cases
#   NAME: test identifier
#   INPUT: assembly source (line number prefix "N: " is stripped)
#   EXPECT_HEX: expected binary output as hex bytes (positive test)
#   EXPECT_FWDREF: expected forward reference count (optional)
#   EXPECT_ERROR: expected error code (negative test - first line only)
#   EXPECT_LINE: expected line number for error
#   EXPECT_MSG: expected error message substring
#   EXPECT_STDERR: multi-line expected stderr output (for traceback tests)
