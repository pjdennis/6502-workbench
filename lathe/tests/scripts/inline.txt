; Scripts for lathe/src/inlinetest.lth and its twin in lathe/tests/test_src_inline.py, which test
; INLINE (lathe/host/inline.py, lathe/src/inlines.lth). Commands:
;   line TEXT (the rest of the line, and a line end, added to the source); text TEXT (without
;   the line end); blank N (N line ends); open (read the source from its start, in the
;   script's file: the first token); next (the next token);
;   func NAME SCOPE FLAGS P R (TYPE REG)... (a function symbol); params F NAME... (a function
;   scope begins with F's parameters, as DECL's head() declares them); save F (inline.save(),
;   then the scope ends; the record); record F;
;   sym KIND SCOPE FLAGS TYPE VALUE NAME (a symbol); freeze SCOPE KIND FLAGS TYPE VALUE NAME
;   (a frozen symbol of an imported module); module NAME; ptr T (a pointer type);
;   write F (to the interface file); read F (from it; then the text memory it took);
;   iface BYTE... (the interface file holds these);
;   enter F WANTED; arg F I (argument_symbol(), the newest operand); begin F (body_begin());
;   tokens (each token replayed to the end, and for a name lookup()'s answer); leave;
;   lookup NAME; lscope (local_scope()); own SIZE (own_slot()); slotname NAME N;
;   copy (copy_aliases()); due (copies_due()); leaves (leaves_operand());
;   istate (level, depth, owned_count, alias_count, saved bytes, each level, owned, alias);
;   isyms FIRST (symbols from FIRST on: name, scope, kind, type, value);
;   gconst T V; glocal T SLOT; gvar S; binary OP; asvalue; accept T; preg T; pop;
;   slot SIZE CLASS KIND NAME; fend FLAGS (gen.function_end(), then the code).
; A token is printed as its number, line, column, and its value (a name, a number) or its
; length and bytes (a string). A record: its place in the buffer, its end, its line, whether
; it has a file name, its flags (1 pure, 2 last return), the variable it writes, each
; parameter's name and whether it is assigned, then its token bytes.
; Kinds: 1 module, 2 function, 3 constant, 4 variable, 5 local, 6 built-in, 7 type, 9 alias.
; Scopes: 0 the module, 1 the module util (regcmd's), $FE predeclared, $FF local, $F0 + level
; an expansion. Symbol flags: 1 pub, 8 at, 16 inline. Types: 1 byte, 2 sbyte, 3 word, 4 int,
; 5 bool; 9 and up made by ptr. Slot classes: 0 zp, 1 either, 2 not zp; kinds 0 parameter,
; 1 local. Operators: 1 + 2 -. Symbols are numbered from 0 in each section; each section's
; source starts empty.
