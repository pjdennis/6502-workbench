; Scripts for lathe/src/regtest.lth (the commands of lathe/src/regcmd.lth) and their twin,
; lathe/tests/regcmd_host.py. A module `m` that imports `util` is being written, with the
; function `m.f` (object symbol 0) being generated; each section starts afresh.
;
; Set up: slot SIZE CLASS KIND NAME; temp SIZE; var TYPE FLAGS SCOPE ADDRESS NAME (a kernel
; symbol); func NAME SCOPE FLAGS PARAMS RESULTS (TYPE REGISTER)...; ftype NAME FLAGS PARAMS
; RESULTS (TYPE REGISTER)... (a function type; flags 1: recursive); ptr TYPE; arr TYPE N ROWS.
; Operands: const TYPE VALUE; wraps; mem TYPE SYMBOL SLOT VALUE MORE VARIABLE; pslot TYPE SLOT;
; preg TYPE; addr TYPE SYMBOL SLOT VALUE; faddr FUNCTION OBJECT; index I; mode I MODE STRIDE;
; pop; swap; squeeze; dup I; keep I; become I KIND TYPE; dtemp I TYPE.
; Code: load R I K; lconst R V; force R V; store R I K; put I K TARGET TK; pconst V TARGET TK;
; imm OP V; alu OP I K; cmp I K; cmpc V; acc OP; modify OP I K; stepx OP; test R; testb I K;
; implied OP; transfer R R; spill I; take I; intomem I; apart I J; unaliased I TARGET KEEP;
; zp I; deref I; clobber; claim R; release I; forget; direct OP I K; use I; loops N.
; Labels: label; place L (reg.label); looplabel L; branch OP L; jump L; join L OTHER.
; Types: accepts T T; assignable I T; fit I T; unify I J; fitf I T; class SYMBOL.
; Looking: show I; state; same I J; offset I K; constb I K; isdirect I; inregs I; slots;
; symweight SYMBOL; value I V (its op_value); retype I T (its op_type); finish (the code, fix-ups, weights and frame); end (the object file).
;
; Types: 1 byte, 2 sbyte, 3 word, 4 int, 5 bool, 6 number, 7 negative, 8 nil.
; Kinds: 1 const, 2 func, 3 var, 4 A, 5 AX, 6 cond, 7 address. Modes: 0 direct, 1 indexed,
; 2 pointer. Flags: 1 temp, 2 zp, 8 data, 16 wraps. Registers: 0 A, 1 X, 2 Y.
; Opcodes (absolute forms): $AD LDA, $6D ADC, $ED SBC, $0D ORA, $2D AND, $4D EOR, $CD CMP,
; $EE INC, $CE DEC, $0E ASL, $4E LSR, $2E ROL, $6E ROR; $18 CLC, $38 SEC, $E8 INX, $CA DEX,
; $60 RTS; branches $F0 BEQ, $D0 BNE.
; No variable: $FFFF. No object symbol (a fixed address): $FFFF. No slot: $FF.
