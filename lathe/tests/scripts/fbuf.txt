; op OPCODE; opb OPCODE BYTE; opw OPCODE WORD; fix OPCODE KIND SYMBOL SLOT ADDEND;
; label (prints its number); labels N (makes N, prints the last); place L; arrive L;
; branch OPCODE L; jump L; call L; join L OTHER; same L; written 0|1; keep; tail; runs;
; used; finish OWN TEMP_BASE (prints code length: code | fix-ups | weights); nops N;
; fixes N (N LDA abs of symbol 0 plus 0, 1, ...).
; Fix-up kinds: 1 address, 2 low, 3 high, 4 zero page (5, shrinks, is FBUF's own choice).

; $40 RTI, $80 BRA, $D0 BNE, $F0 BEQ, $90 BCC, $B0 BCS, $10 BPL, $30 BMI, $50 BVC, $70 BVS.
