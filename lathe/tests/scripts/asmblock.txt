; Scripts for lathe/src/asmtest.lth and its twin in lathe/tests/test_src_asmblock.py. Each
; section is a script, a line `--`, and a piece of Lathe source that the script reads. The
; commands:
;   var T FLAGS SCOPE VALUE NAME (a variable); func NAME SCOPE FLAGS VALUE (a function, at
;   VALUE if FLAGS has 2, extern); const NAME T VALUE; table NAME LENGTH (a constant table of
;   bytes); module NAME N (an imported module, number N); scope (kernel.scope_begin);
;   local NAME SIZE CLASS KIND (a parameter or local: a slot of m.f); static NAME (a `static`
;   word of m.f); type NAME (a named type); loops N (reg.loop_depth); weight S V (a symbol's
;   weight); lconst R V (reg.load_const: A is 0, X 1, Y 2); source (open the section's source);
;   block (pass over line ends to an `asm` token and read the block: then the token, its line
;   and column); asmfunc (pass over line ends and the next line, an `asm func` head, and read
;   the function's lines: then the token, its line and column); finish (fbuf.finish, then the
;   code, fix-ups and weights, and the frame); symweight S (a symbol's weight and flags);
;   end (write the object file); begin (fbuf.begin and reg.begin: a new function m.f).
; Those that make a symbol print its number.
; Types: 1 byte, 2 sbyte, 3 word, 4 int, 5 bool, 6 number. Symbol flags: 2 extern, 8 at,
; 16 zp, 32 nozp. Slot classes: 0 zero page, 1 either, 2 not zero page; kinds 0 parameter,
; 1 local. Tokens: 1 line end, 2 name, 78 end.
; Fix-up kinds: 1 address, 2 low byte, 3 high byte, 4 zero page, 5 address that may shrink.
; Errors are reported in the section's source file: line 1 is the line after `--`.
