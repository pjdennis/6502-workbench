; Scripts for lathe/src/exprtest.lth and its twin in lathe/tests/test_src_expr.py, which test
; EXPR and STMT (lathe/host/expr.py, lathe/src/expr.lth). Each section is a script, a line `--`,
; and a piece of Lathe source that the script's commands read through SRC and LEX. A module `m`
; that imports `util` (module 1) is being written, with the function `m.f` begun; each section
; starts afresh. The commands are those of lathe/tests/scripts/reg.txt (regcmd), and these:
;   source (open the section's source); first (pass over line ends to a token: the token);
;   next (the next token); sym KIND SCOPE FLAGS TYPE VALUE NAME (a symbol); record NAME (a
;   record type: its symbol and type); field S NAME T (a field of record S); enum NAME (an
;   enumeration: its symbol and type); fbegin S (gen.function_begin of function S, recursive if
;   S is); param S NAME... (S's parameters, as DECL declares them: each symbol and slot);
;   receive S; body S (expr.function_body(S): then the token); fend FLAGS (gen.function_end,
;   then the code, fix-ups and weights); expr (expr.expression(): then the token); cond
;   (expr.test(): the label, then the token); econst T (expr.constant(T)); cnum
;   (expr.constant_number(): its value); type (expr.type_spec(): the type); vtype
;   (expr.value_type()); decl LEVEL MORE (expr.variable() at the `var`); save F NAME... (the
;   body of inline function F, its parameters named so, saved from the source as DECL saves it);
;   scope; send (kernel.scope_begin(), scope_end()); gstore; asvalue; accept T; lresult;
;   gjump (gen.jump_false(): the label); efunc (expr.function); initfn S (gen.init_function,
;   then the code); cpu N; syms FIRST (each symbol from FIRST: name, scope, kind, flags, type,
;   value, object number); module NAME; einit (expr.init()).
; A token is printed as its number, line and column; errors are reported in the section's
; source file, whose line 1 is the line after `--`.
; Kinds: 1 module, 2 function, 3 constant, 4 variable, 5 local, 6 built-in (value: 0 lo, 1 hi,
; 2 sizeof, 3 len), 7 type. Scopes: 0 the module, 1 util, $FE predeclared, $FF local.
; Types: 1 byte, 2 sbyte, 3 word, 4 int, 5 bool, 6 number, 7 negative, 8 nil; those a section
; makes are numbered from 9 in order (ptr, arr, ftype, record and enum print them).
; Symbol flags: 1 pub, 2 extern, 8 at, 16 zp (of a function: inline), 32 nozp (of a function:
; interrupt), 64 asm, 128 recursive. Registers of members: 0 none, 1 a, 2 x, 3 y, 4 ax, 5 ay,
; 6 xy, 7 c. Slot classes: 0 zp, 1 either, 2 not zp; kinds 0 parameter, 1 local.
; Tokens: 0 end of file, 1 line end, 78 end.
; Each section names m.f as a function symbol of its own (`func f 0 FLAGS ...`), begins it
; (fbegin), declares its parameters (param), then reads its body (body).
